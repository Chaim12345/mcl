Usage Examples

Basic Usage

// Show global loading loadingManager.showGlobalLoading('Processing...'); // Component loading loadingManager.setComponentLoading(element, true); // Button loading loadingManager.setButtonLoading(button, true); // Progress bar const { element, id } = loadingManager.createProgressBar(); loadingManager.updateProgressBar(id, 75); // Skeleton screen const skeletonId = loadingManager.showSkeleton(container, [ { type: 'title' }, { type: 'text', lines: 3 } ]);

Async Operation Wrapper

// Wrap async operations with loading states await loadingManager.wrapAsyncOperation( async () => { const response = await fetch('/api/data'); return response.json(); }, { globalLoading: true, loadingText: 'Fetching data...', component: myComponent.element, button: submitButton } );
